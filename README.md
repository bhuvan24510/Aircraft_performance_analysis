**Aircraft Performance Analysis Using Python**

 **Project Overview**

This project uses Python to calculate basic aircraft aerodynamic performance parameters using fundamental aerodynamic equations.

 **Objectives**
- Calculate dynamic pressure.
- Calculate lift force.
- Calculate drag force.
- Calculate lift-to-drag ratio.

 **Equations Used**
- Dynamic Pressure: q = 0.5 × ρ × V²
- Lift: L = q × S × CL
- Drag: D = q × S × CD
- Lift-to-Drag Ratio: L/D = Lift / Drag

 **Software Used**
- Python 3
- Google Colab

 **Input Parameters**
- Air density
- Aircraft velocity
- Wing area
- Lift coefficient
- Drag coefficient
